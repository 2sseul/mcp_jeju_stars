# 폐기한 1차 원자료 — 참고용

시스템 프롬프트가 **지금과 다르다.** 이 자료를 지금 결과와 같은 표에 놓으면 안 된다.

당시 프롬프트에는 "되묻지 말 것"·"수치를 함께 쓸 것"·"지도 주소를 실을 것"이
없었다. 그래서 이 자료가 말해 주는 것은 딱 하나다:

- 같은 서버·같은 도구인데 **모델에 따라 도구 선택 정확도가 18%~100% 로 갈렸다**
  (gemma4-e2b-it-qat 18.1% · llama3.1-8b 66.7% · qwen3.5-4b 100.0%).
  이것이 2차에서 모델을 qwen3.5:4b 하나로 고정하고 도구 설명만 바꾸기로 한 근거다.
