# 컨벤션

## 커밋

[Conventional Commits](https://www.conventionalcommits.org/) 형식.

```
<type>(<scope>): <요약>
```

| type | 쓰는 때 |
|---|---|
| `feat` | 새 기능·새 축 |
| `fix` | 버그 수정, 코드리뷰 반영 |
| `refactor` | 동작 변화 없는 구조 변경 |
| `docs` | 문서만 |
| `data` | 데이터 파일 추가·갱신 |
| `test` | 테스트만 |
| `chore` | 빌드·설정·의존성 |

**규칙**

- 제목에는 **주제 하나만** 쓴다. `A + B` 형태로 묶지 않는다 — 그런 커밋은 나눈다.
- 무관한 변경이 섞였으면 **커밋을 나눈다**.
- 단계 라벨(`P1` 등)은 **type 자리가 아니라 본문**에 쓴다.
- 임계값·상수를 바꿨으면 본문에 근거를 적는다. **근거가 없으면 커밋하지 않는다**
  (`docs/decisions.md` §1 에 대장이 있다).
- AI 도구 서명(`Co-Authored-By`, `Generated with …`)은 넣지 않는다.

## PR

- 제목도 커밋과 같은 `<type>(<scope>): <요약>` 형식.
- 본문은 `.github/pull_request_template.md` 구조를 그대로 쓴다.
- 체크리스트는 **실제로 실행해 확인한 것만** 체크한다. 못 채운 항목은 비워두고 "추가 설명"에
  이유를 한 줄 적는다.
- 이슈를 닫을 때는 줄마다 키워드를 반복한다 — `Closes #1, #2` 는 `#1` 만 닫힌다.
- `/pr` 커맨드(`.claude/commands/pr.md`)가 절차를 자동화한다.

## 코드

- **주석·독스트링은 한국어**로 쓴다.
- 긴 함수는 반드시 분리한다 (단일 책임 원칙).
- 문제를 설명할 때는 **원인 · 영향 · 수정 제안**을 간결하게 적는다. 코드 리뷰 코멘트도 동일.
- 상수에는 `#:` 주석으로 **출처**를 남긴다. 문헌값인지 운영값인지 구분해 적는다.
- 계층 규율을 지킨다:
  - `server/core` — 순수 함수. 네트워크·LLM 호출 금지.
  - `server/clients` — 외부 I/O. **예외를 밖으로 던지지 않는다** (실패는 `None` 으로 환원).
  - `server/engine` — 위 둘을 조립.
  - 경로는 **`server/path.py` 를 거친다**. `Path(__file__)` 을 다른 곳에서 쓰지 않는다.
  - `sys.path` 를 조작하지 않는다.

## 테스트

- **Given-When-Then** 패턴으로 쓴다.
- 파일은 `tests/test_<모듈>.py`, 함수는 `test_<상황>_<기대>` 형태.
- 문헌 임계값은 **경계값 자체**(10.0 / 30.0 / 50.0 등)를 반드시 케이스로 넣는다.
- 순수 함수(`core`)는 네트워크 없이 값만 넣고 값만 검사한다.

## 검증 명령

```
uv run ruff check .          # F821 은 0개여야 한다
uv run pytest
uv run python -m server.mcp_server    # 파이프라인 실제 실행
```

경로·import 를 바꿨으면 **파이프라인을 실제로 돌린다**. import 가 통과했다고 동작이
보장되지 않는다.

## 커밋하지 않는 것

- **대용량 바이너리** — `.tif` · `.bsp` · `.npz` · `.img`. 이미 저장소에 있는 것 외에
  새로 추가하지 않는다.
- **라이선스가 재배포를 막는 것** — 크기와 무관하다. `data/elevation/`(FABDEM,
  CC BY-NC-SA 4.0)은 3.5MB 짜리 npz 도 커밋하지 않는다. 재배포하면 **파생물 전체가**
  같은 조건에 묶이기 때문이다(`decisions.md` §2.17). 저장소가 나르는 것은 만드는
  스크립트뿐이고, 받은 사람이 한 번 돌린다.
- **코드가 읽지 않는 원본** — `data/land/`(토지대장 375MB)가 그래서 빠졌다.

새로 빼기로 한 것은 `.gitignore` 에 **왜 빼는지와 함께** 적는다 — 이유가 없으면 다음
사람이 "실수로 빠졌나" 하고 도로 넣는다.
